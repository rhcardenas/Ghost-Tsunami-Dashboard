# Ghost Tsunami Call Center Dashboard

**Interactive Microsoft Excel dashboard for evaluating call center performance, customer satisfaction, and sales outcomes.**

---

## 📌 Project Overview

This project is an end-to-end Excel analytics dashboard designed to assess the performance of Ghost Tsunami’s call center representatives. It enables users to quickly evaluate KPIs such as customer satisfaction (CSAT), call volume, and sales performance through dynamic visualizations and interactive controls.

The dashboard demonstrates advanced Excel dashboarding techniques, data modeling with Power Pivot, and business-focused data storytelling.

---

## 🎯 Goal

Build an interactive Excel dashboard that allows stakeholders to monitor call center performance and compare representatives across key performance metrics including CSAT and sales earned.

---

## 🔄 Process

This project covers the full analytics workflow in Excel:

- Mock data creation
- Data cleaning and transformation
- Relational data modeling
- KPI calculation
- Dashboard design and visualization

## 🚀 Key Features

- **Interactive charts and visuals**

## 🗂 Data Structure

The project uses a structured relational model:

- **Calls (Fact Table)** — core transactional dataset
- **Customers (Dimension Table)** — customer attributes
- **Graphics (Dimension Table)** — dashboard visuals and assets
- **Working Sheet** — staging area for data transformation

## 📊 Dashboard Components

### Call Trend — Combo Area/Line Chart

A dual-series pivot chart combining area and line visuals to show call trends over time while maintaining flexible formatting.

---

### Calls by Weekday — Bar Chart

Visualizes call distribution by weekday to identify operational patterns.

---

### Calls by Gender and City — Stacked Column Chart

Compares demographic performance metrics across locations.

---

### Experience Rating — Column Chart

Highlights customer experience ratings across call reps.

---

### Call Volume & Purchase Amount — Highlighted Bar Charts

Uses dual data series to dynamically highlight selected representatives while keeping peer comparison visible.

---

### Rep Summary — Dynamic KPI Panel

Displays selected rep metrics using live cell references and dashboard logic.

---

### Customer/City/Amount Table

Interactive performance table enhanced with conditional formatting.

---

### Interactive Slicers

Enable fast filtering and exploration across dashboard dimensions.
